## Issues Identified

### 1. LSP False Positives in Mobile App
- **Issue**: Language server shows many "JSX element class does not support attributes" errors
- **Status**: These appear to be TypeScript/Expo type definition mismatches, NOT actual runtime errors
- **Impact**: None - these are lint-time issues that don't affect the build

### 2. Mobile Type Definitions Mismatch
The mobile app defines its own TypeScript interfaces in `src/config/api.ts`, but there are some mismatches with the Prisma schema:

| Mobile Type | Prisma Schema |
|-------------|---------------|
| `Contract.amount_per_cycle` | `Contract.total_amount` |
| `Contract.total_cycles` | (not in schema) |
| `Delivery.quantity_kg` | `Delivery.yield_amount_kg` |
| `Delivery.IN_TRANSIT` | (not in schema - uses HARVESTED) |

### 3. Missing Admin Dashboard
- **Issue**: No admin web interface in mobile app
- **Note**: Admin functionality exists in backend (KYC routes) but no UI to access it
- **Impact**: Medium - need admin panel or web interface

### 4. Environment Variables Required

# New Task: Admin Web App & Type Fixes

## Task 1: Fix Type Mismatches Between Mobile and Backend

### Current Issues
| Mobile Type | Backend (Prisma) | Issue |
|-------------|------------------|-------|
| `Contract.amount_per_cycle` | `Contract.total_amount` | Field name mismatch |
| `Contract.total_cycles` | Not in schema | Field doesn't exist |
| `Delivery.quantity_kg` | `Delivery.yield_amount_kg` | Field name mismatch |
| `Delivery.IN_TRANSIT` | Not in enum (uses HARVESTED) | Status mismatch |

### Solution
Update `mobile/src/config/api.ts` to match Prisma schema exactly:
- Rename `amount_per_cycle` → `total_amount` (or keep and map in API)
- Remove `total_cycles` (not in schema)
- Rename `quantity_kg` → `yield_amount_kg`
- Use schema's `HARVESTED` instead of `IN_TRANSIT`

### Files to Modify
- `mobile/src/config/api.ts` - Update interfaces
